# Limites

Ce fichier liste ce qui n'est pas mesuré et ce que le projet ne prétend pas.

## Non mesuré

Tout, pour l'instant. Aucun test de [EVALUATION.md](EVALUATION.md) n'a encore été lancé.

## Ce que le projet ne prétend pas

- Les clips viennent d'une seule personne et d'un seul téléphone : aucun résultat ne généralise à d'autres personnes ou d'autres caméras.
- Le nombre de clips ne permet aucune conclusion statistique. Un seuil franchi est une règle de décision, pas un résultat « significatif ».
- L'idée d'empiler le temps en volume n'est pas nouvelle.
- Aucun réseau ne tourne dans la page : le site montre des volumes précalculés.
